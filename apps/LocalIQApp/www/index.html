    What's real, step by step

    • Reading files is deterministic code: PDF text layers (table columns kept apart with “ | ”), Word, PowerPoint, Excel, OpenDocument, EPUB, RTF, notebooks, HTML, plain text and source code. Files with an unfamiliar extension are indexed if they look like text.
    • Scanned PDFs and images are read with Windows' on-device OCR. Photos with no text can optionally get an AI-written description (clearly labelled, and it can be wrong).
    • The index is Windows' on-device App Content Search (AppContentIndexer) — a local semantic (vector) and keyword index of your passages. It builds in the background; the header shows its progress.
    • Retrieval blends that semantic index with BM25 keyword ranking, so exact names, codes and numbers and paraphrased questions both work. The sources shown under every answer are exactly what was retrieved.
    • The answer is written by Phi Silica running locally, told to use only the excerpts and cite them as [1], [2]. If they don't contain the answer it should say so.
    • Checks (plain code, not AI): every number in an answer is looked up verbatim in the excerpts the model saw — a ⚠ means it wasn't found there; citations are re-pointed to the passage that really contains the quoted values; a question about something no file mentions returns “not found”.

    Good to know

    • The AI can still misread a table or get a judgment question wrong. Treat answers as a fast pointer — the highlighted source lines are the ground truth.
    • It answers from the few best passages, so it's great for “what / when / how much / where” questions and weaker at “summarize everything” or lists spanning many files.
    • Not supported: audio and video, legacy .doc/.xls/.ppt (save as .docx/.xlsx/.pptx), password-protected files, archives. Very large files are read in part, and the library says so.
    • The on-device model needs a Copilot+ PC. Without one, use “Passages only” — retrieval still works. Windows may download the model once; after that no internet is needed.
    • Windows' on-device index isn't intended for highly sensitive data — index only files you're comfortable having in the local search index.

    Prove it

    This window runs under a security policy that blocks all network requests.

🤖 What is — and isn't — real AI in this demo

The region-of-interest boxes, confidence scores, and priority flags shown on each demo study are pre-authored example data, standing in for what a real medical-imaging detection model would output — no image-detection model is connected in this build. The AI draft impressions, prior-study comparison narration, and this page's copilot answers are genuinely generated live, on-device, by a local language model reasoning only over that structured demo data — never inventing a diagnosis, and never sent anywhere off this device.

⚠ This prototype does not diagnose disease. Every AI finding is labeled "possible" and "requires review." No output from this application should ever be treated as a confirmed diagnosis or a finalized report until a radiologist has explicitly reviewed and signed it.
📥 Imported (real) studies

"Import Study" accepts a real image or DICOM file. DICOM parsing (patient/study metadata, pixel data rendering) is real, deterministic file parsing — the same kind of local processing this app uses for the demo PDFs in its sibling apps, not AI. No automated region-of-interest detection runs on imported studies — this prototype has no validated medical-imaging detection model to connect. You do get a real, on-device, general-purpose image caption (via a generic vision model, not a radiology-specific one) clearly labeled as such, plus full manual tools: your own annotations, your own impression, and sign-off.

📋 Auditability

Every study keeps an audit trail distinguishing AI actions (pre-screening, draft generation) from radiologist actions (opening, accepting/rejecting/modifying findings, writing an impression, signing). See the "Audit Trail" panel on any study for its full history.
